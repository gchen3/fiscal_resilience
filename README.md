# Fiscal Resilience of New York Local Governments

This repository supports an academic research project on fiscal resilience in local governments during crisis events. The study asks how counties, cities, towns, and school districts recover from economic, natural, and public health shocks, including major disasters and the COVID-19 pandemic.

The project is motivated by dynamic capabilities theory. It will measure fiscal resilience using financial indicators such as revenue recovery, spending patterns, and fund balance, then examine how resilience is shaped by structural conditions and government capabilities. Planned explanatory factors include legacy costs, social vulnerability, political environment, prior disaster experience, organizational capacity, and budgetary institutions.

## Current Status

The repository is currently in the data download, import, cleaning, and merge-preparation stage. OSC source data have been downloaded locally, and scripts now focus on transforming raw annual files into analysis-ready entity-year tables.

Current workflow status:

- `data/OSC/` contains the NYS Office of the State Comptroller local government finance download for fiscal years 1995-2025.
- `code/10_import.R` imports raw CSV files for cities, counties, towns, and school districts and writes intermediate `.rds` files.
- `code/20_clean.R` cleans finance records and generates revenue/expenditure variables by entity type and OSC category.
- `code/30_merge.R` merges generated variables into wide processed tables under `data/processed_data/`.
- `code/60_descriptives.R` currently produces summary statistics and `gt` tables.
- `code/40_construct_resilience.R`, `45_construct_predictors.R`, `50_assemble_panel.R`, `70_model_main.R`, `75_model_robustness.R`, and `90_output.R` are scaffolded stubs for the resilience variables, explanatory variables, modeling, and outputs (see `plan_docs/`).

Code is numbered in bands of ten (gaps for inserting stages without renumbering); reusable functions live in `code/functions/`. Although processed `.rds` files may exist locally, the construction, analysis, and output stages should be treated as preliminary.

## Data Source

The primary data source is NYS OSC financial data for local governments. Download notes and the OSC glossary link are in `data/OSC/README.md`. Raw and generated data files are intentionally gitignored because they are large and should be regenerated from source scripts.

## Running the Workflow

Run commands from the repository root so `here::here()` resolves paths correctly.

```r
source("code/00_library.R")
source("code/10_import.R")
source("code/20_clean.R")
source("code/30_merge.R")
source("code/60_descriptives.R")
```

`code/master.R` is the intended workflow driver, but most stages are currently commented out. Uncomment stages as the workflow stabilizes.

Important dependency: `code/30_merge.R` expects objects generated by `code/20_clean.R` to exist in the same R session.
